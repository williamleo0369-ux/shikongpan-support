## 主要功能

- 八字命盘：四柱、结构、岁运与计算依据。
- 紫微斗数：十二宫、星曜、四化与大限流年选择。
- 奇门占事：时空输入、九宫盘局和宫位详情。
- 择时：比较候选日期、时辰与相应条件。
- 罗盘：iPhone 方向与姿态传感器测量，提供二十四山与坐向记录；网页版仅模拟。
- 盘例：本机保存、回看和 JSON 导入导出。
